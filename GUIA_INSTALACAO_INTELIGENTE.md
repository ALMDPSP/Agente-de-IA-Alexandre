# Instalação inteligente — Meu Controle de Peso

Página pública: `https://agente-de-ia-alexandre.onrender.com/instalar`

- iPhone: abrir no Safari → Compartilhar → Adicionar à Tela de Início.
- Android: abrir no Chrome → Instalar app (ou menu ⋮ → Adicionar à tela inicial).
- O botão Android só aparece quando o navegador emite `beforeinstallprompt`; ausência é esperada em alguns navegadores.
- QR Code aponta para a página pública de instalação.
- O aplicativo continua exigindo internet para as operações no Neon.
- Após o deploy, teste `/instalar` em um iPhone e um Android reais.
- Se o QR Code precisar apontar para outro domínio, regenere `static/icons/qr-instalar.png`.
